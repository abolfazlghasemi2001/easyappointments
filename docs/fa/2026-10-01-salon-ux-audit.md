# گزارش بررسی Chromium و ارتقای تجربهٔ آرایشگاه

تاریخ: ۲۰۲۶-۱۰-۰۱

## محدوده

نسخهٔ محلی واقعی برنامه با PHP 8.4 در php-wasm و دیتابیس آزمایشی SQLite اجرا شد؛ صفحات صرفاً ماکاپ نیستند. داده‌های `Company Name`، `Service` و `Jane Doe` نمونه‌های نصب محلی‌اند، نه اطلاعات یک آرایشگاه واقعی. اطلاعات سرور اصلی تغییر نکرده است.

| مشکل | اصلاح و بررسی |

## طراحی و حرکت

- لودینگ زیتونی/ذغالی و طلایی با قیچی متحرک SVG و نوار راه‌راه آرایشگاهی؛ بدون تصویر یا کتابخانهٔ خارجی جدید.
- پایان لودینگ هنگام آماده‌شدن DOM؛ بدون تأخیر نمایشی اجباری یا انتظار برای دانلود تصویر بزرگ. محدودیت ایمنی ۴ ثانیه و بازیابی هنگام `pageshow`.
- با خاموش بودن JavaScript، پوشش لودینگ از ابتدا مخفی است؛ این به معنی کارکرد کامل فرم رزرو بدون JavaScript نیست.
- نشانگر غیرمسدودکننده برای درخواست‌های jQuery که بیشتر از ۱۸۰ میلی‌ثانیه طول می‌کشند.
- حرکت ورود بخش‌ها، واکنش کارت‌ها، خوانایی بهتر متن روی تصویر و رعایت `prefers-reduced-motion` در CSS و انیمیشن‌های jQuery.
- استایل مشترک در رزرو، ورود، پنل مشتری و مدیریت بارگذاری می‌شود.

## نتایج اجرا

- `npx gulp compile`: موفق، شامل CSS معمولی/RTL و JavaScript فشرده.
- `npm run test:js`: موفق؛ ۲۳ بررسی تقویم، ۱۷ بررسی راهنما، ۱۱ بررسی تم/اسلایدر، به‌علاوهٔ تست‌های جدید HTTP، پاسخ‌های دیرهنگام و لودینگ.
- `node dev/sandbox/run.mjs --phpunit`: **۹۳ تست، ۷۵۸۰ assertion، بدون شکست**.
- lint هر پنج فایل PHP جدید/تغییریافته: موفق.
- `npm run test:browser`: موفق در Chromium؛ دسکتاپ ۱۴۴۰×۱۰۰۰ و موبایل ۳۹۰×۸۴۴، رزرو تا مرور نهایی، اعتبارسنجی فیلدهای ضروری، حفظ حالت تیره پس از بارگذاری مجدد، صفحات ورود و پنل مشتری، نبود اسکرول افقی، کاهش حرکت و لودینگ.
- در مسیر smoke نهایی خطای JavaScript یا پاسخ HTTP خطادار مشاهده نشد.
- ورود محلی مدیر و نمایش تقویم مدیریت نیز بررسی و اسکرین‌شات گرفته شد؛ این بررسی، تست کامل همهٔ عملیات مدیریتی نیست.

## محدودیت‌ها

ثبت نهایی رزرو در تست مرورگر عمداً کلیک نشد تا نوبت/پیامک/ایمیل ناخواسته ایجاد نشود. ارسال واقعی TextBee، همگام‌سازی خارجی، رقابت هم‌زمان روی MySQL تولید و همهٔ صفحات مدیریت در این نوبت آزمایش نشده‌اند. موفقیت تست‌های واحد SQLite جای تست انتهابه‌انتهای محیط اصلی را نمی‌گیرد.

## اجرای مجدد

```sh
npm ci
npx gulp compile
npm run test:js
npx playwright install --with-deps chromium
# برنامه را با دیتابیس نصب‌شدهٔ آزمایشی و حداقل یک خدمت/آرایشگر و ساعت آزاد اجرا کنید.
EA_TEST_URL=http://localhost:8080 npm run test:browser
# برای بررسی زبان انگلیسی:
EA_TEST_LOCALE=en-US npm run test:browser
```

در این محیط دانلود مستقیم Chromium و apt در دسترس نبود؛ Chromium بسته‌بندی‌شده اجرا شد. برای مرورگر از پیش نصب‌شده می‌توان `CHROMIUM_PATH` را تعیین کرد. اجرای بدون PHP بومی با `dev/sandbox/setup.sh` و `dev/sandbox/sqlite-dev-db.sh` ممکن است؛ سرور: `APP_ENV=development node dev/sandbox/server.mjs 8080`.

**استقرار:** فایل‌های CSS و JS فشرده طبق قواعد مخزن در Git نیستند. پس از انتشار سورس، `npm ci && npx gulp compile` را در خط ساخت اجرا کنید. هیچ migration جدیدی لازم نیست.
